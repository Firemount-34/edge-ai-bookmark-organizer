## ✨ 功能特性

- 🤖 **多厂商大模型开箱即用**
  - 内置 **DeepSeek (深度求索)**、**硅基流动 (SiliconFlow)**、**阿里云百炼 / 通义千问 (Qwen)**、**火山引擎 (豆包)**、**OpenAI (ChatGPT)**、**Google Gemini** 预设。
  - 支持任意 **自定义 OpenAI 兼容接口** 与本地 **Ollama** 模型。
  - 支持一键「⚡ 测试连接」，API Key 仅保存在本地浏览器的 `chrome.storage.local` 中，无任何第三方中转服务器。
- 🧹 **自动去重与 URL 深度净化**
  - 自动识别并合并重复网址。
  - 自动剥离 URL 中的广告追踪参数（如 `utm_*`、`msclkid`、`gclid`、`fbclid`、`refpid`、`_gl` 等）以及易过期的临时会话参数。
- 🏷️ **智能重命名与两级目录重构**
  - 自动将含义不明的缩写（如期刊投稿系统缩写 `twc`、`wcl`、`cl` 或路由器型号 `D196G`）及冗长的 SEO 标题规范化为清晰易读的名称。
  - 支持自定义分类偏好 Prompt，按「一级大类（带 Emoji）+ 二级子文件夹」构建清爽的两级收藏夹体系。
- 🛡️ **100% 零丢失保障与安全回滚**
  - **数字 ID 映射机制**：大模型仅负责返回书签数字 ID 与规范化标题，原始 URL 完全由本地维护，杜绝大模型幻觉篡改链接。
  - **分批请求防截断**：支持按 80 / 120 / 200 条分批请求，并自动跨批次对齐一级分类；任何未被模型命中的书签自动兜底归入 `📌 其他与未归类`。
  - **双重写入模式**：
    - **🛡️ 安全模式（默认）**：在收藏夹栏下新建 `✨ AI 整理书签 (时间戳)` 文件夹，完全不影响原有书签。
    - **🔄 替换模式**：先自动将当前收藏夹栏完整备份至「其他收藏夹」，再写入新结构；同时支持一键导出标准 Netscape `.html` 书签备份。
- 🖥️ **可视化双栏对比工作台**
  - 左右双栏直观对比「📂 当前收藏夹结构」与「✨ AI 整理后结构预览」，统计卡片实时展示规划前后「X 大类 / Y 子类」及去重计数。
  - 支持在写入浏览器前，点击任意一级分类、二级子文件夹或书签右侧的 `✏️` 按钮在线微调名称。

## 📸 界面预览

- **左侧配置面板**：
  1. **大模型 API 配置**（支持折叠收起）
  2. **整理范围与分类策略**（可选去重、清洗 URL、重命名、自定义 Prompt 与分批大小）
  3. **应用到 Edge 收藏夹栏**（安全模式 / 自动备份替换模式 / 导出 HTML）
- **右侧对比工作区**：
  - 顶部 4 项核心指标卡片（原书签总数、规划前分类数、去重后独立网址、AI 规划后分类数）
  - 左右等高双栏书签树（支持实时关键词搜索、一键全部展开/折叠、统一书签数量徽章）

## 🚀 安装方法（Microsoft Edge / Chrome）

1. **克隆或下载本仓库**
   ```bash
   git clone https://github.com/Firemount-34/edge-ai-bookmark-organizer.git
   ```
2. **开启浏览器开发人员模式**
   - **Microsoft Edge**：在地址栏输入 `edge://extensions/` 并回车，在页面左侧（或右上角）开启 **「开发人员模式」(Developer mode)**。
   - **Google Chrome**：在地址栏输入 `chrome://extensions/` 并回车，在页面右上角开启 **「开发者模式」**。
3. **加载扩展**
   - 点击顶部的 **「加载解压缩的扩展」(Load unpacked)** 按钮，选择本项目所在的 `edge-ai-bookmark-organizer` 文件夹。
4. **打开工作台**
   - 点击浏览器工具栏右上角的 **「AI 书签整理助手」** 图标，即可在新标签页中打开全屏整理工作台。

## 📖 使用指南

1. **配置大模型 API**：
   - 选择服务商预设（例如 `DeepSeek` 或 `硅基流动`），填入你的 `API Key`。
   - 点击 **「⚡ 测试连接」** 确认连通性，点击 **「💾 保存配置」**（保存后可点击右上角 `🔼 收起` 折叠配置栏）。
2. **自定义分类策略**：
   - 选择要整理的目录（默认为 `收藏夹栏`）。
   - 按需勾选「自动去除重复 URL」、「清理广告追踪参数」、「规范化标题」，并在提示词框中补充你的个性化分类偏好。
3. **生成预览并微调**：
   - 点击 **「✨ 开始 AI 智能整理预览」**。
   - 在右侧「✨ AI 整理后结构预览」中检查分类结果，可点击 `✏️` 修改任意目录或书签名称。
4. **写入收藏夹或导出**：
   - 选择「🛡️ 安全模式」或「🔄 替换模式」，点击 **「🚀 确认并写入 Edge 收藏夹」**，或点击 **「📥 导出整理后的 HTML 文件」**。
